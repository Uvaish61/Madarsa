Recommended Build Order

  1. Session core — /auth/signup · login · me · logout (httpOnly cookie). Unblocks every route guard.
  2. Profile + Stats read — /me/profile · /me/stats. Sidebar, Profile, and dashboard cards become real.
    Note: /me/stats has the most leverage — it feeds 4 pages (Dashboard, Courses, Progress, Profile).
  3. Enrollment read — /enrollments. "My Courses" becomes real.
  4. Payments — /orders · /orders/{id}/confirm · /webhooks/payment. The revenue path (never grant enrollment on the client).
  5. Courses CMS — /courses · /courses/{slug} (once courses become editable).
  6. Gamification & Settings — /me/rank · streak · leaderboard · activity · preferences · certificates. Last — static is fine to launch.

🔒 Non-negotiable security

  • Password hashing (bcrypt/argon2) · login rate-limiting · session cookie httpOnly + Secure + SameSite=Lax (NOT a localStorage token — XSS-safe).
  • Order amount must always be computed server-side — never trust a client-sent price. Money = integer paise.
  • Verify the signature on /orders/{id}/confirm and the webhook · idempotency (double-click / retry safe) · the webhook is the source of truth for enrollment.
